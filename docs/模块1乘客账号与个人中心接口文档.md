## 1. 通用约定

### 1.1 统一响应体

所有接口（成功与失败）均返回下列结构，HTTP 状态码与业务码分离：

```json
{
  "code": "0",
  "message": "ok",
  "requestId": "req_2683cb51-32fe-40ad-af24-cd11ad053d86",
  "data": { }
}
```

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `code` | string | `"0"` 表示成功；失败时为业务错误码（见 §10） |
| `message` | string | 面向用户的提示，可直接展示；内部错误统一为「服务内部错误，请稍后重试」 |
| `requestId` | string | 链路追踪 ID；请求头传 `X-Request-Id` 则原样回传，否则生成 `req_<uuid>`，响应头同步返回 |
| `data` | object \| null | 成功时为业务数据；失败时固定为 `null` |

序列化约定（`internal/server/response.go`）：

- 字段名使用 proto 原始 **snake_case**；
- 输出零值字段（集合输出 `[]`、数值输出 `0`），前端无需判空即可遍历；
- `int64` 输出为 **JSON 数值**（非 proto3 默认的字符串）；
- `proto3 optional` 字段未传时输出 `null`；
- 时间统一 ISO 8601 + 北京时间偏移，如 `2026-10-27T13:54:16+08:00`；`sign_in_date` 为 `2026-10-27`。

### 1.2 鉴权

除 2 个登录相关接口外，其余 11 个接口都必须携带令牌：

```http
Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
```

- 令牌为 JWT（HS256），有效期 **2 小时**（`biz.AccessTokenTTL`），载荷含 `sub`(乘客ID)、`pno`(乘客编号)、`iss`、`jti`、`exp`；
- 每次请求会回查账号状态，**冻结/注销账号的存量令牌立即失效**（返回 `403 FORBIDDEN`）；
- 缺失或失效令牌统一返回 `401 UNAUTHORIZED`；
- 所有查询强制按令牌中的乘客 ID 隔离数据，不接受客户端传入的乘客 ID。

### 1.3 分页

列表接口强制分页，禁止返回全量（`biz/common.go`）：

| 参数 | 默认值 | 上限 | 说明 |
| --- | --- | --- | --- |
| `page` | 1 | — | 小于等于 0 按 1 处理 |
| `page_size` | 20 | **50** | 超过 50 按 50 处理 |

响应统一含 `items`、`total`、`page`、`page_size`。

### 1.4 数据安全

- 手机号在响应与日志中一律脱敏：`138****0000`（`biz.MaskMobile`）；
- 验证码只存哈希（`hash(verification_id + code)`），任何接口都不返回真实验证码；
- 登录审计表不保存验证码、令牌明文。

## 3. 登录认证

### 3.1 发送登录短信验证码

`POST /api/v1/passenger/auth/sms-codes`　（无需鉴权）

**请求体**

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `mobile` | string | 是 | 大陆手机号；服务端会去掉空格/`-`/`+86` 前缀后校验 `^1[3-9]\d{9}$` |
| `scene` | string | 否 | 固定 `LOGIN`（空值默认 `LOGIN`，其他值报「不支持的验证码场景」） |

```json
{ "mobile": "13800000000", "scene": "LOGIN" }
```

**响应 data**

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `verification_id` | string | 验证码挑战编号，登录时必须回传 |
| `expires_in_seconds` | int32 | 有效期，固定 300 秒（`SmsCodeTTL`） |
| `resend_after_seconds` | int32 | 冷却期，固定 60 秒（`SmsResendInterval`） |
| `masked_mobile` | string | 脱敏手机号，用于前端确认发送目标 |

```json
{
  "code": "0",
  "message": "ok",
  "requestId": "req_2683cb51-32fe-40ad-af24-cd11ad053d86",
  "data": {
    "verification_id": "verify_a17cf285a0230f79271a0638",
    "expires_in_seconds": 300,
    "resend_after_seconds": 60,
    "masked_mobile": "138****0000"
  }
}
```

**规则**

- 同一手机号 60 秒内重复请求 → `429 RATE_LIMITED`「验证码发送过于频繁，请稍后再试」；
- 验证码为 6 位数字随机数，**不落库、不进日志**（联调时可开 `RIDE_SMS_ECHO_CODE=1` 输出到服务日志）；
- 短信通道发送失败会立即作废本次挑战；
- Redis 不可用时自动退化为进程内存储（仅限单实例联调）。

### 3.2 手机号验证码登录 / 注册

`POST /api/v1/passenger/auth/mobile-login`　（无需鉴权，T0）

**请求体**

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `mobile` | string | 是 | 与发码时一致（同样做规范化 + 格式校验） |
| `sms_code` | string | 是 | 6 位数字验证码；非 6 位数字报「验证码格式不正确」 |
| `verification_id` | string | 否 | 发码返回的挑战编号；为空时按手机号取最近一次未消费的挑战 |
| `device_id` | string | 否 | 客户端设备号，仅用于登录审计（`passenger_auth_records.device_id`） |

```json
{ "mobile": "13800000000", "sms_code": "887252", "verification_id": "verify_a17cf285a0230f79271a0638", "device_id": "local-test" }
```

**响应 data**

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `passenger` | object | 乘客摘要，结构见 §3.3 |
| `access_token` | string | JWT 令牌，后续接口放 `Authorization: Bearer <token>` |
| `expires_in_seconds` | int32 | 令牌有效期，7200 秒 |
| `is_new_user` | bool | 是否本次新注册（前端可据此引导实名 / 新人券） |

```json
{
  "code": "0",
  "message": "ok",
  "requestId": "req_175effaf-3889-4add-ad95-4aeca33e3163",
  "data": {
    "access_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "expires_in_seconds": 7200,
    "is_new_user": true,
    "passenger": {
      "id": 4,
      "passenger_no": "P1793080456907556",
      "mobile": "138****0000",
      "nickname": "乘客0000",
      "avatar_url": "",
      "real_name_status": 0,
      "account_status": 1,
      "point_balance": 0,
      "preferences": {
        "order_notification_enabled": true,
        "promotion_notification_enabled": true,
        "security_notification_enabled": true,
        "trip_share_default_enabled": false
      },
      "created_at": "2026-10-27T13:54:16+08:00"
    }
  }
}
```

**业务规则**

1. 手机号不存在时**自动注册**：事务内创建 `passengers` 记录（编号 `P` + 纳秒时间戳，昵称「乘客+手机号后 4 位」）并同时初始化 `passenger_wallets`（余额 0，`version=0` 乐观锁）；
2. 验证码校验通过后**立即删除挑战**，保证一次性消费，防止并发重放；
3. 同一挑战验证码错误累计 5 次（`SmsMaxAttempts`）→ 挑战作废并返回 `429 RATE_LIMITED`「验证码错误次数过多，请重新获取」；
4. 挑战与手机号不匹配、挑战不存在、已过期统一返回「验证码已失效，请重新获取」，不泄露挑战归属；
5. 账号被冻结（`account_status=0`）或注销（`=2`）→ `403 FORBIDDEN`「账号已被冻结或注销，请联系客服」；
6. 每次尝试（成功/失败）都写入 `passenger_auth_records` 审计：脱敏手机号、`auth_type=1`、`login_result`、失败原因、`device_id`、`client_ip`（取自 `X-Forwarded-For` / `X-Real-Ip`）、`user_agent`。

### 3.3 乘客摘要对象 `PassengerSummary`

| --- | --- | --- |

## 4. 个人中心

### 4.1 个人中心聚合查询

`GET /api/v1/passenger/profile`　（鉴权）

无请求参数。一次返回资料 + 钱包 + 券 + 未读消息 + 签到摘要，避免首页多次请求。

**响应 data**

| 字段 | 类型 | 说明 |
| --- | --- | --- |

| `wallet_balance` | double | 钱包余额（元），来自 `passenger_wallets.balance` |
| `available_coupon_count` | int32 | 可用券张数（状态 0 且未过期） |
| `unread_notification_count` | int32 | 未读消息数 |
| `signed_in_today` | bool | 今日是否已签到（北京时间自然日） |
| `continuous_sign_in_days` | int32 | 连续签到天数 |

```json
{
  "code": "0",
  "message": "ok",
  "requestId": "req_xxx",
  "data": {
    "passenger": { "id": 4, "passenger_no": "P1793080456907556", "mobile": "138****0000", "nickname": "乘客0000", "avatar_url": "", "real_name_status": 0, "account_status": 1, "point_balance": 0, "preferences": { "order_notification_enabled": true, "promotion_notification_enabled": true, "security_notification_enabled": true, "trip_share_default_enabled": false }, "created_at": "2026-10-27T13:54:16+08:00" },
    "wallet_balance": 0,
    "available_coupon_count": 0,
    "unread_notification_count": 0,
    "signed_in_today": false,
    "continuous_sign_in_days": 0
  }
}
```

**错误**：`401 UNAUTHORIZED`（无令牌/失效）、`404 RESOURCE_NOT_FOUND`（乘客不存在）、`403 FORBIDDEN`（冻结/注销）。

### 4.2 偏好设置

`PATCH /api/v1/passenger/settings`　（鉴权）

**请求体**

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `preferences.order_notification_enabled` | bool | 否 | 订单状态通知 |
| `preferences.promotion_notification_enabled` | bool | 否 | 活动/优惠通知 |
| `preferences.security_notification_enabled` | bool | 否 | 安全类通知（服务端忽略关闭请求，始终为 true） |
| `preferences.trip_share_default_enabled` | bool | 否 | 行程默认分享开关 |

```json
{ "preferences": { "promotion_notification_enabled": false, "trip_share_default_enabled": true } }
```

**行为**：PATCH 语义 —— 只覆盖显式传入的字段，其余保持原值；合并结果写入 `passengers.preferences`（JSONB），并**返回合并后的完整偏好**，前端直接以此刷新开关状态。

```json
{ "code": "0", "message": "ok", "requestId": "req_xxx",
  "data": { "preferences": { "order_notification_enabled": true, "promotion_notification_enabled": false, "security_notification_enabled": true, "trip_share_default_enabled": true } } }
```

## 5. 常用地址

> 所有地址接口都按 `passenger_id` 隔离：越权访问他人地址一律按「资源不存在」返回，避免探测资源是否存在。

### 5.1 地址列表

`GET /api/v1/passenger/addresses?page=1&page_size=20&address_type=1`　（鉴权）

| 参数 | 位置 | 必填 | 说明 |
| --- | --- | --- | --- |
| `page` | query | 否 | 默认 1 |
| `page_size` | query | 否 | 默认 20，上限 50 |
| `address_type` | query | 否 | 1 家 / 2 公司 / 3 常用站点；非法值报「地址类型不合法」 |

**响应 data**：`items`（地址对象数组）、`total`、`page`、`page_size`。

**地址对象 `PassengerAddress`**

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | int64 | 地址 ID |
| `address_type` | int32 | 1 家 / 2 公司 / 3 常用站点 |
| `address_name` | string | 名称，≤60 字符 |
| `address` | string | 详细地址，≤255 字符 |
| `longitude` / `latitude` | double | 经纬度（GCJ-02），范围 -180~180 / -90~90 |
| `station_id` | int64 | 关联 `stations.id`；站点表由模块3交付，未落地前固定返回 0 |
| `is_default` | bool | 是否默认（同一乘客同类型只允许一个默认） |
| `last_used_at` | string | 最近使用时间，未使用为 `null` |
| `created_at` / `updated_at` | string | 创建/更新时间 |

### 5.2 新增地址

`POST /api/v1/passenger/addresses`　（鉴权）

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `address_type` | int32 | **是** | 1/2/3 |
| `address_name` | string | **是** | 非空，≤60 字符（按 Unicode 字符数） |
| `address` | string | **是** | 非空，≤255 字符 |
| `longitude` | double | 否 | 默认 0，范围校验 |
| `latitude` | double | 否 | 默认 0，范围校验 |
| `station_id` | int64 | 否 | 不可为负 |
| `is_default` | bool | 否 | 为 true 时把同类型其他地址置为非默认 |

**响应 data**：`{ "address": { ... } }`

### 5.3 修改地址

`PATCH /api/v1/passenger/addresses/{id}`　（鉴权）

请求体字段与新增一致但**全部可选**，仅更新显式传入的字段；`id` 在路径中。响应同上。

**错误**：`400 INVALID_ARGUMENT`（id ≤ 0）、`404 RESOURCE_NOT_FOUND`（不存在或非本人）。

### 5.4 删除地址

`DELETE /api/v1/passenger/addresses/{id}`　（鉴权）

```json
{ "code": "0", "message": "ok", "requestId": "req_xxx", "data": { "id": 12, "deleted": true } }
```

**错误**：重复删除、越权删除均返回 `404 RESOURCE_NOT_FOUND`「常用地址不存在」。

| --- | --- | --- |

## 8. 实名认证

> 数据安全：姓名与身份证号**不明文入库**，只保存掩码（`张*` / `110105********002X`）与加盐 SHA-256 哈希；哈希盐值来自环境变量 `RIDE_ID_CARD_SALT`，未配置时使用兜底盐值并打印告警（仅限本地联调）。

### 8.1 提交实名认证

`POST /api/v1/passenger/real-name`　（鉴权）

**请求体**

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `real_name` | string | 是 | 2-30 个字符，允许中文、英文字母、空格与间隔号（`·`/`•`），首尾空格自动去除 |
| `id_card_no` | string | 是 | 18 位大陆身份证号；校验前 17 位为数字、出生日期合法（1900 年至今）、GB 11643 校验位，末位 `x` 自动转大写 |

```json
{ "real_name": "张三", "id_card_no": "11010519491231002X" }
```

**响应 data**

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `real_name_status` | int32 | 提交后的乘客实名状态，固定 `1`（认证中） |
| `real_name_masked` | string | 姓名掩码，仅保留首字 |
| `id_card_masked` | string | 证件掩码，保留前 6 位与后 4 位 |
| `submitted_at` | string | 提交时间（ISO 8601 +08:00） |

```json
{
  "code": "0",
  "message": "ok",
  "requestId": "req_xxx",
  "data": {
    "real_name_status": 1,
    "real_name_masked": "张*",
    "id_card_masked": "110105********002X",
    "submitted_at": "2026-10-27T15:02:11+08:00"
  }
}
```

**业务规则**

1. 提交成功后：`passenger_real_name_records.status = 1`，同时同事务把 `passengers.real_name_status` 置为 `1`（认证中）；
2. 乘客**已认证**（`real_name_status = 2`）时不允许重复提交 → `409 BUSINESS_CONFLICT`「已完成实名认证，无需重复提交」；
3. 认证中（1）与驳回（3）**允许重新提交**，覆盖原记录：重置状态、清空驳回原因与审核时间（便于更正资料后重新送审）；
4. 同一证件号不允许绑定多个账号：若该证件哈希已被其他乘客的「认证中/已认证」记录占用 → `409 BUSINESS_CONFLICT`「该身份证号已绑定其他账号」；
5. 一名乘客只保留一条认证记录（`uk_passenger_real_name_passenger`），覆盖式更新；
6. 审核（通过 → 2 / 驳回 → 3 + 驳回原因）由后台人工或后续模块接口流转，本模块只负责提交与查询；
7. 日志只输出掩码，不打印证件原文。

### 8.2 查询实名认证状态

`GET /api/v1/passenger/real-name`　（鉴权）

**响应 data**

## 10. 错误码

| HTTP | code | 触发场景 |
| --- | --- | --- |
| 200 | `"0"` | 成功 |
| 400 | `INVALID_ARGUMENT` | 手机号/验证码格式错误、地址字段校验失败、实名姓名/证件号格式或校验位错误、分页外的参数非法、验证码已失效/不正确 |
| 401 | `UNAUTHORIZED` | 未携带令牌、令牌无效或过期 |
| 403 | `FORBIDDEN` | 账号冻结/注销 |
| 404 | `RESOURCE_NOT_FOUND` | 乘客不存在、地址不存在（含越权访问） |
| 409 | `BUSINESS_CONFLICT` | 默认地址等可重试的业务冲突、**已完成实名认证重复提交**、**身份证号已绑定其他账号** |
| 429 | `RATE_LIMITED` | 验证码发送过于频繁（60s 内）、验证码错误次数超限（5 次） |
| 500 | `INTERNAL_ERROR` | 未预期异常（对外只返回「服务内部错误，请稍后重试」） |

> 未在文档枚举内的错误码统一降级为 `INTERNAL_ERROR`，避免泄露实现细节（`internal/server/response.go`）。
